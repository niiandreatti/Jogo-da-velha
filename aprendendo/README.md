# ❌ Jogo da Velha (Tic-Tac-Toe) em React ⭕

Um clássico Jogo da Velha moderno, interativo e responsivo, desenvolvido com **React** e **Vite**. Este projeto foi construído como parte do aprendizado prático de conceitos fundamentais de desenvolvimento frontend, como gerenciamento de estados (`useState`), componentes reutilizáveis, lógica condicional e estilização moderna.

---

## 🚀 Funcionalidades

- **Controle de Partida:** O tabuleiro inicia travado e só é liberado após clicar em "Iniciar Jogo".
- **Alternância de Turnos:** O sistema alterna automaticamente entre o **X** e o **O** a cada jogada válida.
- **Detecção de Vitória:** Identifica automaticamente linhas, colunas e diagonais vencedoras.
- **Detecção de Empate ("Deu Velha"):** Reconhece quando o tabuleiro está cheio sem vencedores.
- **Pop-up de Fim de Jogo (Modal):** Um alerta visual flutuante com efeito de vidro fosco (`backdrop-filter`) exibe o resultado da partida e permite reiniciar instantaneamente.
- **Botão Dinâmico:** Alterne facilmente entre iniciar uma nova partida ou reiniciar o jogo em andamento.

---

## 🛠️ Tecnologias Utilizadas

- **React** (Hooks: `useState`)
- **JavaScript (ES6+)**
- **HTML5 & CSS3** (Flexbox, design responsivo e temas escuros customizados)
- **Vite** (Ambiente de desenvolvimento rápido)
